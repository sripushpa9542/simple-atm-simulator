# Simple ATM Simulator Using Python

A beginner-friendly Python mini project that simulates basic ATM operations.

## Features

- Register with a username and custom 4-digit PIN
- Log in using the registered username and PIN
- Check account balance
- Deposit money
- Withdraw money when sufficient balance is available
- Validate transaction amounts and handle invalid numeric input
- Log out and return to the main menu

## Technologies Used

- Python 3
- Functions
- Dictionaries
- Conditional statements
- While loops
- Exception handling

## Initial Balance

Each newly registered user starts with a simulated balance of ₹5,000.

## How to Run

1. Open `atm_simulator.py` in Python 3 or an online Python compiler.
2. Run the program.
3. Select **Register** and create a username and 4-digit PIN.
4. Select **Login** and enter your registered details.
5. Choose an ATM operation from the menu.

## Limitations

Account details and balances are stored in memory and are lost when the program exits. This is an educational simulation, not a real banking system.
